# Лабораторная работа №2. C++ и регулярные выражения (вариант: Markdown)

| Задание | Функции | Файл |

## Сборка

### Visual Studio 2019/2022 (проще всего)
`Файл -> Открыть -> Папка...` и выбрать каталог `lab2` (в нём `CMakeLists.txt`). Затем `Сборка -> Собрать всё`, запуск `lab2.exe`.

Или из командной строки разработчика:
```
cmake -S . -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
build\Release\lab2.exe
```

### Linux / MinGW
```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/lab2
```

Каталог `data` копируется рядом с исполняемым файлом автоматически. Если словарей нет, берутся встроенные.

## Запуск

```
lab2                                   интерактивное меню
lab2 check файл.md                     задание 1: проверить файл
lab2 find  файл.md [лимит] [--skip-check]   задание 2 (сначала проверка, затем поиск)
```
Для файла на 20 ГБ используйте командную строку: файл читается построчно, в памяти хранится не более `лимит` элементов каждого вида (по умолчанию 1000), а счётчики считают всё. На тестовом файле 40 МБ проверка и поиск вместе занимают около 1,3 с.

## Как работает определение языка разметки

Текст читается построчно, и считаются признаки:
- **AsciiDoc**: `= Заголовок`, `:атрибут:`, `[source,...]`, `NOTE:`, `|===`, `** вложенный`, `. нумерованный`, `image::...[]`;
- **HTML**: теги `<html>`, `<div>`, `<p>`, `<h1>`, `<ul>` и т. д.;
- **Markdown**: заголовки `#`, блоки кода, ссылки `[т](у)`, цитаты `>`, таблицы; списки считаются слабым признаком (в AsciiDoc они тоже есть).

Если признаков HTML или AsciiDoc больше, чем сильных признаков Markdown, выводится ошибка «текст является HTML/AsciiDoc». Для текста, признанного Markdown, проверяются ошибки: нет пробела после `#`, больше 6 решёток, незакрытый блок кода, незакрытая скобка в ссылке.

Это эвристика, а не полноценный разбор по спецификации CommonMark. На защите стоит сказать об этом прямо.

## Формат анкеты

Пример из задания:
```
Вход:  Сидоров ИваН ПетРОви1ч 2002-03-01 +7996-8432-431 sidorovVV@pochta.ru
Выход: Сидоров Иван Петрович 01.03.2002 +79968432431 sidorovvv@pochta.ru
```
Допустимые форматы даты: `ГГГГ-ММ-ДД`, `ГГГГ.ММ.ДД`, `ГГГГ/ММ/ДД`, `ДД.ММ.ГГГГ`, `ДД-ММ-ГГГГ`, `ДД/ММ/ГГГГ`. Телефон: `+7…`, `7…`, `8…` или 10 цифр, пробелы, скобки и дефисы допускаются. Несуществующие даты (31.02), будущие даты, номера неверной длины и почта без `@` отклоняются с сообщением.

## Замечания
- Исходники в **UTF-8**. В Visual Studio ключ `/utf-8` уже прописан в `CMakeLists.txt`.
- Консоль Windows переключается в UTF-8 в `main.cpp` (`SetConsoleCP(65001)`).
- Словари в `data/` собраны мной из распространённых имён, а не скачаны из конкретного открытого источника. Если по заданию нужен определённый словарь, замените файлы (по одному слову в строке, строки с `#` игнорируются).
